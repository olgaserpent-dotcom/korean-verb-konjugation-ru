# Тренажёр спряжений корейских глаголов

Веб-приложение для отработки спряжения корейских глаголов: показывает словарную форму глагола и нужную грамматическую форму, пользователь вводит ответ и сразу видит, верно ли он справился. Приложение само подсовывает те формы, которые встречались реже всего — так тренировка равномерно покрывает весь материал.

Работает полностью локально, в браузере, без сервера и базы данных — весь прогресс хранится в `localStorage` браузера.

## Возможности

- Настраиваемый набор тренируемых форм — 9 грамматических групп (настоящее/прошедшее/будущее время, повелительное и пригласительное наклонение, атрибутивные формы, прикладные конструкции и др.), чекбоксы на экране настроек.
- Умный подбор пары «глагол + форма»: чаще показываются те пары, которые встречались реже всего.
- Мгновенная проверка ответа с подсветкой (зелёный — верно, красный — ошибка).
- При ошибке счётчик показов этой пары обнуляется, чтобы она снова попалась в ближайшее время.
- После ответа показывается правильная форма и перевод глагола.
- База глаголов редактируется вне приложения — в Excel/Google Sheets — и конвертируется в данные приложения одной командой.

## Что нужно для запуска (чистая установка)

Приложению нужен только **Node.js** (включает `npm`). Никаких баз данных и серверов ставить не нужно.

### macOS

Если Node.js ещё не установлен:

```bash
# 1. Установить Homebrew (если его нет)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. Установить Node.js
brew install node
```

Проверить, что всё встало:

```bash
node --version   # нужна версия 22.6 или новее
npm --version
```

### Windows / Linux

Скачать и установить Node.js LTS с [nodejs.org](https://nodejs.org/) (версия 22.6+), либо через менеджер версий (`nvm`, `fnm` и т.п.).

## Как запустить проект

```bash
# 1. Склонировать репозиторий
git clone https://github.com/olgaserpent-dotcom/korean-verb-konjugation-ru.git
cd korean-verb-konjugation-ru

# 2. Установить зависимости (один раз)
npm install

# 3. Запустить локальный сервер разработки
npm run dev
```

Терминал покажет адрес вида `http://localhost:5173/` — откройте его в браузере.

Чтобы остановить приложение — `Ctrl+C` в терминале.

Другие полезные команды:

| Команда | Что делает |
|---|---|
| `npm run dev` | Запустить приложение локально (для повседневного использования) |
| `npm run build` | Собрать статическую production-версию в папку `dist/` |
| `npm run preview` | Запустить собранную версию из `dist/` |

## Как обновить список глаголов (добавить новые)

Таблица глаголов ведётся в Excel/Google Sheets, а не внутри приложения. Формат — как в исходном файле: первая строка — названия групп форм, вторая строка — названия конкретных форм внутри группы, дальше — по одной строке на глагол (словарная форма, перевод, значения всех форм по порядку колонок).

1. Откройте вашу таблицу глаголов, добавьте новые строки (новые глаголы) или отредактируйте существующие. **Не меняйте порядок и состав колонок** — конвертер ожидает ровно ту же структуру групп/форм, что и в исходном файле. Пример заполненной таблицы моно посмотреть в папке `sample` текущего репозитория.
2. Экспортируйте таблицу в CSV с разделителем `;` (в Google Sheets: Файл → Скачать → Значения, разделённые запятой (.csv), затем при необходимости пересохранить с `;`; в Excel — Файл → Сохранить как → CSV с указанием `;` как разделителя списков в региональных настройках).
3. Прогоните конвертер, указав путь к вашему CSV-файлу:

   ```bash
   npm run convert:csv -- /путь/к/вашему/файлу.csv
   ```

4. Скрипт перезапишет [public/verbs.json](public/verbs.json) и выведет количество сконвертированных глаголов. Обновите страницу в браузере (если `npm run dev` уже запущен) — новые глаголы сразу появятся в тренировке.

Никакой пересборки проекта не требуется — только повторный запуск конвертера.

## Как пользоваться приложением

1. **Настройки** (кнопка «⚙ Настройки» вверху экрана тренировки). Отметьте чекбоксами те грамматические формы, которые хотите тренировать — можно выбрать как отдельные формы, так и целую группу целиком (чекбокс у названия группы). Нажмите «Начать тренировку».
2. **Тренировка.** На экране появляется словарная форма глагола и название требуемой формы. Введите вашу версию ответа в поле ввода и нажмите «Проверить» (или Enter).
3. **Проверка.** Поле ввода подсветится зелёным при верном ответе или красным при ошибке. Под полем появится правильная форма глагола и его перевод.
4. Нажмите **«Далее»** (та же кнопка, что была «Проверить») — появится следующая пара «глагол + форма». Система в первую очередь выбирает то, что вам встречалось реже всего; ошибочные ответы обнуляют счётчик показов, поэтому такие формы вернутся быстрее.
5. Прогресс сохраняется автоматически в браузере — можно закрыть вкладку и продолжить позже. Прогресс привязан к конкретному браузеру на конкретном компьютере и не синхронизируется между устройствами.
